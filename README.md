# 工序按键引导程序 (Process Key Guide)

一个用于引导用户按特定顺序按下按键的Python GUI应用程序。适用于培训、演示或需要按特定步骤操作键盘的场景。

## 功能特性

### 核心功能
- **工序管理**：添加、修改、删除、调整工序顺序
- **按键引导**：开始引导后，屏幕右上角显示独立提示窗口
- **循环模式**：支持循环引导，一轮完成后自动返回第一步
- **ESC退出**：在循环模式下，按ESC键可随时退出引导
- **颜色自定义**：可自定义提示窗口的文字颜色、背景颜色和透明度
- **数据持久化**：自动保存工序列表和设置到JSON文件

### 用户界面
- 直观的GUI界面，使用tkinter构建
- 工序列表显示，支持增删改查操作
- 独立的无边框置顶提示窗口（标题：按键提示）
- 实时状态显示和操作反馈

## 安装要求

### 系统要求
- Python 3.6 或更高版本
- tkinter库（通常Python自带）

### 安装步骤
1. 克隆或下载本项目
2. 确保已安装Python 3.x
3. 运行程序：
   ```bash

   ```

## 使用方法

### 基本使用
1. **添加工序**：点击"添加工序"按钮，输入显示名称和按键
2. **开始引导**：点击"开始引导"按钮，屏幕右上角显示提示
3. **按键响应**：按照提示按下正确的按键
4. **停止引导**：点击"停止引导"按钮或按ESC键（循环模式下）

### 高级功能
- **循环模式**：勾选"循环模式"复选框，使引导可以循环进行
- **颜色设置**：使用颜色选择器自定义提示窗口外观
- **透明背景**：勾选"透明背景"使窗口半透明
- **数据保存**：点击"保存数据"按钮保存当前设置

## 常见问题

### Q: 程序无法启动
A: 确保已安装Python 3.x和tkinter库。在命令行中运行`python --version`检查Python版本。

### Q: 提示窗口不显示
A: 检查屏幕分辨率设置，程序将窗口定位在屏幕右上角。确保没有其他全屏程序遮挡。

### Q: 按键没有响应
A: 确保程序窗口处于活动状态。在循环模式下，按ESC键可以退出引导。

### Q: 数据保存失败
A: 检查当前目录的写入权限。程序需要权限创建和修改`process_data.json`文件。
